# Mejiro31 v0.5.1

設定サイト: https://jeebis27.github.io/Mejiro31/

共通メジロ式エンジンを更新し、動詞・一般略語の入力規則と片手入力、Undo の動作を反映しました。内蔵メジロ式の辞書は追加登録を96件まで保存できます。日本語・英語のQWERTY版UF2を配布し、サイトの辞書検索・逆引きに使用するデータも同じエンジンへ更新しました。逆引きは構文解析の有無を選べます。

- `jp` はIME切り替えキーを持つ日本語プロファイル、`en` は記号キーを優先する英語プロファイルです。代替配列はUF2書き込み後にサイトから選択してください。
- 書き込み前にサイトで現在の設定を書き出してください。24/28件版からの辞書保存データ移行は行いません。
- BOOTSELを押しながらUSB接続し、RPI-RP2ドライブにUF2をコピーしてください。
- 書き込み後は設定サイトまたは標準Vialアプリからキー割当を変更できます。

ホストテストとUF2検証は、実機の入力・USB・IME動作を確認するものではありません。
