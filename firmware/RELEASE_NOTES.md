# Mejiro31 v0.5.0

設定サイト: https://jeebis27.github.io/Mejiro31/

キーマップ・Tap/Hold・二段圧縮コンボ・代替配列・JIS/US・メジロ式辞書設定をブラウザーから編集・保存できます。入力テストとキーマップPNG保存にも対応しました。

Mejiro31 Vial対応ファームウェアです。QWERTYを初期配列とする日本語・英語の2種類を配布します。代替配列はUF2書き込み後、設定サイトから選択して保存してください。

- `jp` はIME切り替えキーを持つ日本語プロファイル、`en` は記号キーを優先する英語プロファイルです。
- 書き込み前に、現在の設定をサイトで書き出してください。ファームウェアの変更時はキー割当と配列設定が初期化されます。
- BOOTSELを押しながらUSB接続し、RPI-RP2ドライブにUF2をコピーしてください。
- 書き込み後は設定サイト、または標準Vialアプリでキー割当を変更できます。代替配列やJIS/US設定は専用サイトで変更してください。
- サイトでは、物理キー・二段圧縮の固定26組の出力・Tap/Holdを編集できます。通常のQMKマクロ、Tap Dance、任意のCombo定義は対象外です。
- 起動時は書き込みロックがオフです。サイトで手動ロックすると、解除するか本体を再起動するまでロックを維持します。解除は上段の左右両端を長押しします。

自動ビルドとホストテストは、実機の入力・USB・IME動作の検証を代替するものではありません。

- コンボ受付・連続入力猶予・長押し判定時間を、サイトの「キーボード設定」で変更し、本体へ保存できます。

- 2uのSpace/Enterとその下の各1uキーの間に、未割り当ての親指コンボ4組を追加しました。

- メジロ式の追加辞書を24件から28件に拡張。既存の保存形式と4 KiB二重バンクを維持します。
